# spor_takip_uygulamasi

A new Flutter project.

This project demonstrates the integration of modern mobile development practices:

* **🔐 User Authentication:** Secure sign-up and login processes using **Firebase Auth**.
* **📋 Workout Management:** Users can create custom workout programs (Push/Pull/Legs) and log exercises.
* **☁️ Real-Time Database:** All workout logs and user data are instantly synced using **Cloud Firestore**.
* **📈 Progress Tracking:** Visualizing weight changes over time with dynamic charts based on date inputs.
* **⚡ Reactive UI:** Smooth and responsive user interface optimized for both iOS and Android.
This project is a starting point for a Flutter application.

## 🛠 Tech Stack & Architecture

* **Language:** Dart
* **Framework:** Flutter (3.x)
* **Backend:** Firebase (Authentication, Firestore Database)
* **State Management:** [Provider / Riverpod / GetX - Kullandığını buraya yaz]
* **Architecture:** MVC (Model-View-Controller) pattern ensuring clean code and scalability.
